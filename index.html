1. Secure Corporate Knowledge Base Query Engine (AI & Backend)

End-to-End Retrieval-Augmented Generation Pipeline

Python / FastAPI / LangChain / ChromaDB

Project Overview: I built a complete intelligence pipeline that lets businesses securely query private documents. The system parses text files, partitions them into 1000-character segments using overlapping sliding matrices to preserve context, and translates them into vector embeddings. When a user asks a question, the backend conducts a cosine similarity search inside a vector database and routes the grounded context to an LLM, entirely eliminating hallucinations.

2. Industrial Smart Environment Telemetry Node (IoT & Embedded)

Microcontroller Firmware & Stream Ingestion Architecture

C++ / ESP32 / MQTT / Node.js

Project Overview: I designed and implemented an automated sensor collection network. Written in native C++ using the Arduino IDE framework, the firmware runs on an ESP32 microcontroller to gather temperature and moisture metrics via physical GPIO hardware pins. The data is serialized into light JSON structures and broadcasted asynchronously over a Wi-Fi link via the MQTT protocol to a central server gateway for real-time tracking.
